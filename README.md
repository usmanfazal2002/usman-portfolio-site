## 🌐 How to Host on GitHub Pages (Free Live Website)

1. Go to your repository settings on GitHub: `Settings` → `Pages`.
2. Under **Build and deployment** → **Source**, select `Deploy from a branch`.
3. Choose branch: `main` (or `master`), folder: `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live at:
   ```text
   https://usmanfazal2002.github.io/<repository-name>/
   ```

---

## 🔌 How to Install as a WordPress Theme

If you want to run this in WordPress:

1. Download `usman-portfolio-theme.zip` from this repository.
2. In your WordPress admin dashboard, navigate to:
   **Appearance → Themes → Add New Theme → Upload Theme**.
3. Select `usman-portfolio-theme.zip` and click **Install Now**.
4. Click **Activate**.
