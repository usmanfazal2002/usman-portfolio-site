# Syed Usman Fazal — Portfolio Website

Personal portfolio for Syed Usman Fazal, an Odoo and web developer. The root
site is a static website that can be hosted on GitHub Pages. This repository
also includes a WordPress theme version.

## Repository contents

- `index.html` — standalone portfolio website.
- `assets/css/` and `assets/js/` — assets used by the current standalone site.
- `wordpress-theme/usman-portfolio/` — WordPress theme source.
- `usman-portfolio-theme.zip` — installable WordPress theme archive.
- `style.css`, `js/`, and `img/` — assets from the standalone version included
  with the WordPress theme source.

## Deploy on GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, then
select the `main` branch and the root (`/`) folder.

## Install the WordPress theme

In WordPress, go to **Appearance → Themes → Add New Theme → Upload Theme** and
select `usman-portfolio-theme.zip`. Install and activate the theme.
